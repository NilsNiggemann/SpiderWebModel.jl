# SpiderWebModel.jl
[![DOI](https://zenodo.org/badge/763516137.svg)](https://doi.org/10.5281/zenodo.20441119)

This repository contains code that was used to simulate classical and quantum properties of the spiderweb model.
- It is meant for documentation and reproducibility purposes and should not be imported as a package to run custom code.
- This repository contains code for simulation and evaluation of data. Parts of this code may be exploratory and do not correspond to data featured in any publication.
- Figures from publications may be easier to reproduce by using the zenodo archive: https://zenodo.org/records/16781381 which also contains the raw data.
For an implementation of the Green function Monte Carlo method for generic models, please refer to my julia package [GreenFunctionMonteCarlo.jl](https://github.com/NilsNiggemann/GreenFunctionMonteCarlo.jl)
